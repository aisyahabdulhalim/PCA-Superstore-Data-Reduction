# Data Reduction Using PCA on the Superstore Dataset

This repository contains a Principal Component Analysis (PCA) of the Superstore Dataset. The project was completed for **MDA3083 - Predictive Analytics** at Universiti Malaysia Terengganu.

PCA was applied to reduce four numerical retail variables - **Sales, Quantity, Discount, and Profit** - into a smaller set of uncorrelated principal components while retaining as much information as possible.

## Project objectives

- Apply PCA as a data-reduction technique.
- examine the eigenvalues and explained variance;
- identify the most important principal components;
- interpret the component loadings;
- visualize the PCA results using a scree plot and score plot; and
- derive practical insights into retail performance and purchasing behavior.

## Dataset

The project uses the Superstore Dataset, which contains **9,994 observations** and **21 original variables** representing retail transactions in the United States.

The four variables selected for PCA are:

| Variable | Description |
|---|---|
| Sales | Revenue generated by a transaction |
| Quantity | Number of products purchased |
| Discount | Discount applied to the transaction |
| Profit | Profit or loss generated by the transaction |

Dataset source: [Superstore Dataset on Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

The dataset is not included in this repository. Download it from the source and save it locally as:

```text
data/Superstore Dataset.xlsx
```

## Methodology

The analysis was performed in R using `princomp()` with `cor = TRUE`. This means PCA was conducted using the **correlation matrix**, which standardizes the variables before calculating the components.

The workflow consisted of:

1. importing the Excel dataset;
2. selecting Sales, Quantity, Discount, and Profit;
3. checking and preparing the numerical data;
4. fitting the PCA model;
5. calculating eigenvalues and explained variance;
6. examining component loadings;
7. producing a scree plot and PCA score plot; and
8. interpreting the retained components.

## Results

Four principal components were produced.

| Component | Eigenvalue | Variance explained | Cumulative variance |
|---|---:|---:|---:|
| PC1 | 1.590 | 39.75% | 39.75% |
| PC2 | 1.059 | 26.47% | 66.22% |
| PC3 | 0.881 | 22.03% | 88.25% |
| PC4 | 0.470 | 11.75% | 100.00% |

Under the **Kaiser criterion**, components with eigenvalues greater than 1 are retained. Therefore, PC1 and PC2 were selected. Together, they preserve approximately **66.22%** of the total variance.

## Component loadings

| Variable | PC1 | PC2 |
|---|---:|---:|
| Sales | 0.643 | 0.218 |
| Quantity | 0.289 | 0.631 |
| Discount | -0.270 | 0.719 |
| Profit | 0.655 | -0.195 |

### PC1: Business Performance

PC1 has strong positive loadings for **Profit** and **Sales**. It represents overall business performance and revenue generation. Higher PC1 scores generally correspond to transactions with stronger sales and profit performance.

### PC2: Discount and Purchasing Behavior

PC2 has strong positive loadings for **Discount** and **Quantity**. It represents a dimension associated with promotional strategy and the number of products purchased.

The signs of PCA loadings can be reversed without changing the mathematical meaning of a component. Interpretation should therefore focus mainly on the relative magnitude and pattern of the loadings.

## Correlation with Sales

The calculated correlations were:

- Sales and PC1: **0.81**
- Sales and PC2: **0.22**

Sales is strongly associated with PC1 and only weakly associated with PC2. This supports the interpretation of PC1 as the primary business-performance dimension.

## Business implications

The analysis suggests that:

- Sales and Profit jointly represent an important business-performance dimension.
- Discount and Quantity form a second dimension associated with promotional and purchasing behavior.
- Four original variables can be represented by two components while retaining approximately 66.22% of their standardized variance.
- PCA can simplify exploratory analysis, but the retained components should not be treated as direct proof of causal relationships.
